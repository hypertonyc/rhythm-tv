# Rhythm TV

Просмотр сериалов из торрента на старом Samsung Smart TV: сервер раздаёт файлы
из торрента как HLS, клиент на телевизоре их играет.

Репозиторий содержит обе части.

| Каталог | Что это |
|---|---|
| [client/](client/) | приложение для Samsung Smart TV (Tizen 2.3, телевизоры 2015 года) |
| [server/](server/) | медиасервер на Go: торрент → ffmpeg → HLS + встроенный веб-клиент |
| [scripts/](scripts/) | сборка и установка клиента на телевизор |
| [.vscode/](.vscode/) | задача VS Code, запускающая сборку |

## Как это работает

```
торрент  ──anacrolix──>  server/ (Go)  ──ffmpeg──>  HLS (MPEG-TS + WebVTT)
                              │                          │
                              │  /api/files, /api/probe   │  /hls/<id>/...
                              v                          v
                       client/ на телевизоре  ──AVPlay──>  экран
```

Сервер ничего не качает заранее и перекодирует только тот эпизод, который
просят, — H.264 + AAC в MPEG-TS, потому что декодер 2015 года другого
не понимает. Клиент опрашивает готовность сегментов и стартует, когда их
появилось хотя бы два.

Торрентов на сервере может лежать сколько угодно, но активен всегда один —
тот, что показывается на телевизоре. Новый `.torrent` загружают со страницы
сервера (она открывается и с телефона), там же переключают активный; телевизор
подхватывает смену сам.

За местом на диске сервер следит сам: когда свободного остаётся мало, он
удаляет скачанное, начиная с серий, которые дольше всех не смотрели. Ничего
при этом не теряется — серию можно открыть снова, она докачается.

## Быстрый старт

Сервер (нужен Docker, либо Go 1.26 + ffmpeg):

```sh
cd server
docker build -t torrent-media-server .
docker run --rm -p 8000:8000 -v /path/to/torrents:/data torrent-media-server /data/file.torrent
```

Каталог `/data` — библиотека: положенные туда `.torrent` видны сразу, а открыв
`http://<сервер>:8000/` с телефона, можно загрузить новый и выбрать активный.
Монтировать его на запись обязательно, иначе загрузка работать не будет.

Подробности и список эндпоинтов — [server/README.md](server/README.md).

Клиент (нужны Tizen SDK tools и сертификат для подписи):

```sh
cp .env.example .env   # пути к тулчейну, адрес телевизора, профиль, DEFAULT_SERVER
./scripts/tizen-build-install.sh
```

В VS Code то же самое — **Run Build Task** → `Tizen: Build & Install on TV`.
Подробности — [client/README.md](client/README.md).

Ограничения платформы и неочевидные решения в коде — [CLAUDE.md](CLAUDE.md).
